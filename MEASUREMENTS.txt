11) PROMPT INJECTION DEFENSE (OWASP LLM01) — VERIFIED 2026-07-27
================================================================================

Threat model:
  WebScraperPlugin fetches attacker-controlled pages. That text enters chat
  history of an LLM with auto function calling over WebSearch, WebScraper, and
  VectorMemory. A hostile page can attempt to:
    (a) override the system prompt / change the agent's goal
    (b) call VectorMemory.Save to poison future retrievals
    (c) exfiltrate context via WebScraper to attacker.com/?data=<secrets>
    (d) chain: poison memory now, trigger on a later unrelated query
  The original 43 SecurityTests guard the INPUT boundary only. This section
  covers the CONTENT boundary (what tools return).

Controls implemented (structural — regex is NOT the enforcement point):
  1. Provenance: ContentProvenance {Trusted, Untrusted} + TaintedContent.
     WebScraper/WebSearch return Untrusted. VectorMemory persists
     provenance=untrusted + origin_url in Qdrant payload; retrieval surfaces it.
  2. Spotlighting: per-session crypto-random delimiter id
     (<untrusted_web_content id="{8-byte-hex}">…</untrusted_web_content>).
     Delimiter smuggling neutralized before wrap. System prompt treats markers
     as DATA, never instructions / tool authorization.
  3. Sanitization: strip U+200B–U+200D, U+FEFF, bidi U+202A–U+202E / U+2066–U+2069;
     NFKC normalize; cap ContentSanitizer.MaxContentLength = 2500 chars.
  4. InjectionPolicyFilter (IAutoFunctionInvocationFilter):
       allowlist → budget (8/turn, 40/session) → tainted-sink → exfiltration.
       Tainted-sink carve-out (narrowed 2026-07-27 grading session): allow Save
       when UserRequestedMemorySave OR text grounded in user message; payload
       still tagged provenance=untrusted. Page-induced Save without user
       save-intent remains blocked.
       Exfil: unauthorized URL, context-substring leak, attacker.* shapes
       (query / path / subdomain / fragment). High-entropy query alone is NOT
       sufficient (caused 29/40 benign-page FPs — narrowed away).
